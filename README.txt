 BOT DUOLINGO REDEEM — by @Drosek
=========================================

SETUP
─────
1. Install Node.js 18+   →  https://nodejs.org
2. Install Google Chrome →  https://google.com/chrome
3. Buka folder ini di Terminal / CMD
4. Install dependencies:
      npm install
5. Edit file .env  →  isi CAPSOLVER_API_KEY
6. Jalankan bot:
      npm start

KONFIGURASI (.env)
──────────────────
  REDEEM_CODE          Kode promo Duolingo
  EMAIL_DOMAIN         Domain email custom (kosong = wds.my)
  PASSWORD             Password akun (kosong = random)
  CAPSOLVER_API_KEY    API CapSolver — WAJIB diisi!
  DEFAULT_CONCURRENCY  Jumlah browser paralel (max 5)
  MINIMIZE_WINDOW      true = browser jalan di background
